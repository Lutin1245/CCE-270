# Project layout

This is a single-file web app. Keep `AGENTS.md`, `spec.md`, `prompts.md`, and
`index.html` at the project root. GitHub Pages needs `index.html` at the root.

Save every new file in the appropriate location:

- `00_planning/` for planning notes and sketches.
- `01_data/` for data files.
- `02_validation/` for hand calculations and test cases.
- `03_output/` for screenshots and exported results.

Do not move the four root-level files into these folders.
