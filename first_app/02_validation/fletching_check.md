# Fletched force-arrow check

- Point-load arrows have a shaft, an enlarged directional arrow character, and two fletching pairs fanned backward from the tail. The second pair is farther down the shaft and at the same angle.
- Every arrow in a uniform-load row has the same enlarged character and aligned backward-fanned fletching.
- Upward reactions use an enlarged `↑` character and backward-fanned fletching.
- Reaction force values and span labels sit below the upward arrows without overlapping them.
- A load with magnitude `3.14` still displays π characters instead of downward arrows.
